* **O Problema:** A rotina incluía 10 km de caminhada diária de retorno de Campinas somados a 100 flexões, 100 abdominais e 100 agachamentos (Treino Saitama completo). Isso sobrecarregava as pernas e a lombar, drenando a energia física necessária para o raciocínio matemático à tarde e à noite.

### 💻 Problema 5: CSES 1068 — Bugs de Implementação em C++

Durante o desenvolvimento do [**`Weird_Algorithm.cpp`**](file:///home/henrique/pratica_deliberada/CSES/Weird_Algorithm.cpp), foram identificados 4 desafios técnicos sucessivos:

#### A. Loop com tamanho fixo (`for`)
* *Bug:* O código original usava um `for` com tamanho fixo em 8.
* *Correção:* A conjectura de Collatz tem número imprevisível de passos; a estrutura correta é o `while (n != 1)`.

#### B. Erro de Acesso à Memória Nula (Segmentation Fault)
* *Bug:* O código declarava `vector<int> numbers_imputs;` (tamanho 0) e tentava ler com `cin >> numbers_imputs[0]`.
* *Diagnóstico com AddressSanitizer:*
  ```text
  runtime error: reference binding to null pointer of type 'int'
  AddressSanitizer: SEGV on unknown address 0x000000000000
  ```
* *Lição de C++:* Em C++, `vector<int> v;` não pré-aloca índices. Acessar `v[0]` tenta escrever no ponteiro nulo (`0x0`). Para usar vetores dinâmicos vazios, deve-se usar `.push_back()`.

#### C. Uso Ineficiente de Memória
* *Insight:* O problema pede apenas para exibir os números em tela separados por espaço. Não há necessidade de guardar o histórico em vetor ($O(N)$ de memória). O uso de uma única variável escalar reduz o consumo de memória para **$O(1)$** (memória constante).

#### D. Estouro de Inteiro (*Integer Overflow*)
* *Bug potencial:* Para entradas $n$ de até $10^6$, a operação intermediária $n \times 3 + 1$ estoura o limite do `int` de 32 bits ($2 \times 10^9$).
* *Correção:* Uso obrigatório de **`long long`** (64 bits).

#### E. Padrão de Performance de Atleta de CP
* *Otimização:* Adicionadas as diretivas de Fast I/O (`ios_base::sync_with_stdio(false); cin.tie(NULL);`) e a quebra de linha limpa final `\n` em vez de `endl`.

## 🏆 3. Código Final Validado

Arquivo: [`CSES/Weird_Algorithm.cpp`](file:///home/henrique/pratica_deliberada/CSES/Weird_Algorithm.cpp)

```cpp
#include <iostream>

using namespace std;

int main() {
    // Fast I/O: Desacopla C++ streams do C stdio
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    long long n;
    cin >> n;
    cout << n;

    while (n != 1) {
        if (n % 2 == 0) {
            n /= 2;
        } else {
            n = n * 3 + 1;
        }
        cout << " " << n;
    }

    cout << "\n";
    return 0;
}
```

* **Testes Locais:**
  * Entrada `3` $\rightarrow$ Saída `3 10 5 16 8 4 2 1` ✅
  * Caso de borda `1` $\rightarrow$ Saída `1` ✅
  * Teste de estresse com `138367` $\rightarrow$ 162 passos executados instantaneamente sem estouro ✅
