# 2.3 - Estruturas de Controle

As estruturas de controle permitem que você decida quais partes do código serão executadas ou quantas vezes serão repetidas. Se você já programou em JavaScript, o C++ vai ser muito familiar aqui.

## Condicionais (`if` e `else`)
- O `if` executa um bloco se uma condição for verdadeira.
- O `else if` e o `else` oferecem caminhos alternativos.

## Loops (Repetição)
- **`while`**: Repete enquanto a condição for verdadeira.
- **`for`**: Ideal para repetições com contador (ex: 0 a 10).

## Controle de Fluxo
- **`break`**: Sai do loop imediatamente.
- **`continue`**: Pula para a próxima iteração do loop atual.
