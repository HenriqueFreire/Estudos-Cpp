# Capítulo 2 - Conceitos Básicos de C++

Este capítulo cobre os pilares fundamentais da linguagem C++. Se você vem de linguagens como TypeScript ou JavaScript, notará que o C++ oferece muito mais controle sobre a memória e o ciclo de vida dos dados.

## O que vamos aprender:

### [2.1 - Variáveis](./2.1-Variaveis/)
Tipagem estática, tipos primitivos (`int`, `double`, `char`, `bool`) e o uso moderno do `auto` (inferência de tipo).

### [2.2 - Instruções](./2.2-Instrucoes/)
O conceito de *statements* em C++ e como cada linha de código é executada.

### [2.3 - Estruturas de Controle](./2.3-Estruturas-de-controle/)
Decisões (`if`, `else`) e repetições (`while`, `for`, `break`, `continue`).

### [2.4 - Funções](./2.4-Funcoes/)
Como organizar o código em blocos reutilizáveis, declaração vs. definição e o tipo especial `void`.

### [2.5 - Tipos definidos pelo Usuário](./2.5-Tipos-definidos-pelo-usuario/)
Criação de estruturas (`structs`) para agrupar dados, o equivalente às interfaces no TS para definir "formas" de dados.

### [2.6 - Referências](./2.6-Referencias/)
Um dos conceitos mais importantes do C++: como passar dados sem copiá-los e como o `const` garante a segurança.
