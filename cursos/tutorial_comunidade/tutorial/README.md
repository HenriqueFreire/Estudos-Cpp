# Tutorial de C++ para Desenvolvedores Modernos

Bem-vindo ao tutorial de C++! Este repositório foi criado para ajudar desenvolvedores (especialmente aqueles que vêm de ecossistemas como TypeScript/JavaScript) a aprenderem C++ de forma prática e profissional.

O projeto utiliza ferramentas da indústria como **CMake**, **Nix-shell** e **Clang-Format** para garantir um ambiente de desenvolvimento robusto e padronizado.

## Estrutura do Curso

### [Capítulo 1: Introdução](./1-Introducao/)
Configuração do ambiente, primeiro programa "Olá Mundo" e ferramentas de build.

### [Capítulo 2: Conceitos Básicos](./2-Conceitos-basicos/)
Variáveis, instruções, estruturas de controle, funções, structs e o uso essencial de referências.

## Como usar este repositório?

1. **Ambiente:** Se você usa Nix, basta rodar `nix-shell` na pasta `tutorial/` para ter todas as ferramentas (compilador, debugger, formatador) prontas.
2. **Formatação:** O projeto segue o **Google C++ Style**. Use `clang-format` para manter seu código limpo.
3. **Exploração:** Cada pasta possui seu próprio `README.md` detalhando os conceitos e os códigos de exemplo.

---
> **Objetivo:** Mais do que apenas aprender a sintaxe, este curso foca em entender **como a memória funciona** e como escrever código C++ de alta performance.
