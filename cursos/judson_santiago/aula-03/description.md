# Aula 03 - Cálculos com Variáveis, Constantes e Tipos de Dados

Este diretório contém exemplos da Aula 03 de Programação de Computadores, focados em cálculos, manipulação de variáveis, uso de constantes e diferentes tipos de dados.

## Conteúdo

- `variaveis.cpp`: Demonstra como realizar cálculos utilizando múltiplas variáveis, onde o resultado de uma operação pode ser usado para definir o valor de outra variável.
- `constantes.cpp`: Exemplo didático de como usar constantes em C++, mostrando diferentes maneiras de definir e utilizar valores que não podem ser alterados durante a execução do programa.
- `tipo-de-variaveis.cpp`: Exemplo didático de diferentes tipos de variáveis em C++, demonstrando a declaração e o uso dos tipos de dados mais comuns.
- `atribuicao.cpp`: Exemplo didático de operadores de atribuição em C++, mostrando como usar o operador de atribuição simples (=) e os operadores de atribuição composta (+=, -=, *=, /=, %=).

## Como Compilar e Executar

Para compilar e executar os programas, siga os passos abaixo. É necessário ter um compilador C++ (como o g++) instalado no seu sistema.

### Compilação

Abra um terminal no diretório `aula-03` e use o comando `g++` para compilar cada arquivo:

```bash
g++ variaveis.cpp -o variaveis
g++ constantes.cpp -o constantes
g++ tipo-de-variaveis.cpp -o tipo-de-variaveis
g++ atribuicao.cpp -o atribuicao
```

Isso criará os arquivos executáveis `variaveis`, `constantes`, `tipo-de-variaveis` e `atribuicao`.

### Execução

Após a compilação, você pode executar os programas da seguinte forma:

```bash
./variaveis
./constantes
./tipo-de-variaveis
./atribuicao
```

Cada programa exibirá seus resultados ou demonstrações no terminal.
