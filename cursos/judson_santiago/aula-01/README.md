# Aula 01 - Introdução à Programação em C++

Este diretório contém os primeiros exercícios e exemplos da Aula 01 de Programação de Computadores. Os arquivos `.cpp` são os códigos-fonte em C++, e os arquivos sem extensão são os executáveis compilados correspondentes.

## Conteúdo

- `primeiro.cpp`: Primeiro programa C++.
- `segundo.cpp`: Segundo programa C++.
- `terceiro.cpp`: Terceiro programa C++.

## Como Compilar e Executar

Para compilar e executar os programas, siga os passos abaixo. É necessário ter um compilador C++ (como o g++) instalado no seu sistema.

### Compilação

Abra um terminal no diretório `aula-01` e use o comando `g++` para compilar cada arquivo:

```bash
g++ primeiro.cpp -o primeiro
g++ segundo.cpp -o segundo
g++ terceiro.cpp -o terceiro
```

Isso criará os arquivos executáveis `primeiro`, `segundo` e `terceiro`.

### Execução

Após a compilação, você pode executar os programas da seguinte forma:

```bash
./primeiro
./segundo
./terceiro
```

Cada comando executará o programa correspondente no terminal.
